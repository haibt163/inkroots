# Ink Roots

A bilingual (English / Vietnamese) learning app for the **214 Kangxi radicals**. Each radical has stroke-order animation, Mandarin pronunciation, a short mnemonic, and example words.

## Stack

- TanStack Start + React 19
- Tailwind CSS v4
- Zustand (learned radicals, persisted locally)
- [hanzi-writer](https://github.com/chanind/hanzi-writer) for stroke order
- Web Speech API (`zh-CN`) for pronunciation

No account or database. Progress and language preference live in `localStorage`.

## Data

The radical list is generated by `scripts/generate-radicals.py`:

1. Official Kangxi glyphs, pinyin, and stroke counts (1–214)
2. Cross-checked against [chinese-radicals.json](https://github.com/nicolas-jaussaud/chinese-radicals) and [this gist](https://gist.github.com/branneman/f93d596ac236f0dbd9fb5b1a5099122f)
3. Vietnamese meanings, stories, combining forms, and 2–4 example words added programmatically

Regenerate with:

```
python3 scripts/generate-radicals.py
```

Stroke animation data is fetched on demand from the hanzi-writer-data CDN when you open a radical. If a rare form has no data, the glyph is shown still.

## Run locally

```
npm install
npm run dev
```

No environment variables or API keys.

## Features

- Browse, search, and filter all 214 radicals by stroke count and frequency
- Detail page: playable stroke order, trace-it quiz, audio, examples
- Instant English ↔ Vietnamese UI (meanings and stories included)
- Meaning quiz on `/practice`
- Mark radicals as learned (saved on this device)
